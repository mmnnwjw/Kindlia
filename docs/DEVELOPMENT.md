# 开发说明

Kindlia 是独立的 AutoNovel Kindle 客户端，复用 KinNovel 的平台、渲染、分页与交互组件。上游归属与许可见 THIRD-PARTY-NOTICES.md 和 UPSTREAM-FILES.json；不依赖开发者的 KinNovel 工作目录。

接口以源站实际源码为准，核对入口见 PROTOCOL.md。普通读者功能包括账号、收藏、阅读历史、发现、搜索、排行、书籍评论和文库下载阅读；不接入论坛页面、小说上传编辑、翻译任务管理或 KinNovel 的账号与自动更新服务。

## KinNovel 参考基线

当前基线为 [KinNovel v1.6.8 / 4bcfee767ba0ae3f154c189646d406951bb61f89](https://github.com/mmnnwjw/KinNovel/commit/4bcfee767ba0ae3f154c189646d406951bb61f89)，上一基线为 v1.6.6 / 3f89ad2953bfda5378d9856aea5bb4c7ebc09265。仅使用已提交源码；开发者工作目录中的未提交修改不属于基线。

已移植两版之间适用的平台更新：广告版屏保模块的卸载与恢复、自定义休眠封面期间保持窗口管理器暂停、原生状态栏的停用与恢复、退出后恢复帧缓冲并刷新，以及 Scribe 启动方向和不同代 Oasis 陀螺仪编码处理。启动锁、临时文件及持久性数据路径仍与 KinNovel 隔离；不移植其自动更新、账号服务、产品版本号或历史发布文档。复用文件及适配差异记录在 UPSTREAM-FILES.json。

阅读器插图只对已解码位图实际显示的矩形开放全屏预览，不包含分页预留框中的留白。阅读统计入口位于「我的 → 阅读统计」，沿用 KinNovel 的今日、近 7 天、累计、连续天数、14 天图表和书籍排行。统计仅保存在程序目录内的 data/stats.json，不上传；单页计时上限 5 分钟，每 20 次有效翻页及离开阅读器、换章、休眠时保存，加载或浏览子页面期间不计时。同一文库书的已知来源卷合并统计。

## 开发与配置

构建、安装和字体路径见根目录 README.md。默认直连，反代地址与密钥为空；反代需用户自行部署并配置，见 GATEWAY.md。已有配置不会因默认值调整而被覆盖。

段间距 paragraph_spacing 默认 0.1，设置界面范围 0–2.0，步进 0.05，排版器不支持负段距。它以基础行高为单位增加文本块后的间隔，中日对照里的译文和日文各自属于一个文本块。EPUB 富文本（包括标题）的段后间隔取该值与 CSS margin-bottom 的较大值，并另外保留下个块的 margin-top；0 不会抹去源文件样式或独立空段。非富文本标题、图片和分隔线使用各自的间隔。行高 line_spacing 默认 1.4，设置界面范围 1.0–2.0，步进 0.05；它以字号的倍数控制同一段内的行高。

设备程序与持久性数据统一放在 /mnt/us/extensions/kindlia/ 内，包括配置、会话、字体、日志、缓存和备份。旧目录自动迁入该目录，冲突文件和迁移备份保留在内部 backups/。普通更新保留数据，清洁安装需要显式指定。

本地数据、账号文件、构建产物、诊断截图与日志不进入 Git。性能调试报告、设备测试记录、迁移交接及历史发布记录保留在被忽略的本地目录，不上传仓库。不要在提交中加入真实反代密钥、密码、令牌、设备 IP 或 SSH 指纹。

## EPUB 支持范围

支持 EPUB2 NCX、EPUB3 nav 目录、XHTML 正文、栅格插图及嵌有栅格图片的 SVG 封面；支持常用内联/外链 CSS 选择器及粗体、对齐、缩进、间距、隐藏等排版属性，以及跨文件注释。目录按 spine 和有效锚点组织，正文渐进分页，缓存最近章节和邻页位图。

尚不支持完整浏览器 CSS、@import/@media/@font-face、内嵌字体、复杂表格/浮动、竖排或任意纯矢量 SVG。无 BOM 的 UTF-16 和其他旧编码不保证支持。单章 CSS、规则匹配和注释解析有资源上限；超限会明确报错，缺失可选 CSS 会跳过。

## 性能调试

优先实际登录、浏览和阅读操作，在本地保存输入、显示画面和分阶段耗时。模拟器的 TCG 时间不能替代实机 CPU 或面板的光学测量。旧观察记录不能当作当前版本已重新验证的证据。

KN_DEBUG 启用输入与刷新诊断；账号输入时关闭，避免输入日志包含敏感信息。诊断文件应保留在被忽略的 build 目录或设备程序目录内。

## 列表、评论与网络任务

收藏请求 level=0 表示全部分级，level=1 仅一般向；收藏分页与源站保持一致。Web 与文库标准列表均不返回作者，仅在响应提供或已有本地详情缓存时回显，不逐本请求。Web 目录使用 createAt，缺失保持空白；详情更新时间取有效章节时间最大值，文库只显示 latestPublishAt 出版日期。

前台 API、图片网络、后台预加载/更新和本地解码分别使用固定工作队列；缓存命中和 EPUB 插图走本地队列。阅读器优先当前页，再相邻页；回调按页面代次及图片尺寸隔离，损坏缓存会删除，失败可稍后重试。插图局部刷新与呈现记录沿用参考基线。

评论支持粗体、斜体、删除线、行内代码、HTTP(S) 链接、列表、换行、剧透、星级和折叠内容。回复编辑器提供格式说明和本地预览，不发送草稿。Kindlia 独立更新的签名、镜像和恢复见 UPDATES.md，不连接 KinNovel 更新端点。

## 位置、缓存与弹窗

阅读器复用 AnchorIndex，在恢复锚点、改变字号和向前跨章时先排到确定位置，再呈现首帧；其余章节继续渐进分页。按章节保存独立进度，shelf.json 保留最近阅读聚合；旧进度 JSON 和书签位置元组继续可读。书签标题与摘录保存在独立元数据中，列表从缓存章节名回退，不向用户展示 XPath。字号在阅读菜单和设置中统一使用逻辑 300 DPI 的 24–96、步进 2，布局时换算设备 DPI。

封面位图按 8 MiB 预算逐项 LRU 淘汰，失败保留缺省图并冷却后重取；缓存 JSON 和原图读取按小时更新使用时间，避免每次命中都写入闪存。前台 API 复用 ServerHealth 并合并同账号/同资源的并发 GET，短时缓存按账号状态和修改操作隔离；刷新令牌串行处理且重检旧令牌。图片使用单次下载和有限重定向，文库大文件单独保留续传。

标准二按钮确认使用 widgets::dialog，多项选择继续使用居中 Choice；运行时在每次绘制前捕获内嵌弹窗背景。实机路径以干净上一帧作为弹窗底图、以实际屏幕像素作为差分基准，避免把按压反相留在背景中。只有显式根页显示四个 Tab，二级目录、收藏夹选择和搜索保留返回导航。

内置符号和 Emoji 字体取自所记载的 KinNovel 基线，连同原许可证打包；包内许可证并入既有 THIRD-PARTY-NOTICES.md，以兼容旧版安装器的文件白名单。系统中日文字体仍作为回退；缺少基础字形会记录告警，成功的样本检查只在 KN_DEBUG 下输出。

系统只读字体使用按需分页的文件映射，内置字体直接引用静态字节，避免启动时将整份字体复制到堆；可替换的用户字体继续使用独立数据。字体日志中的 file_or_static_bytes 是映射/静态资源长度，不等于实际驻留内存。

REST 与图片下载共享有界 HTTP/1.1 空闲连接池，按源站和 TLS 配置隔离，完整消费响应和 chunked trailers 后才归还连接。陈旧连接只允许 GET/HEAD 重试一次，修改请求不自动重放；EPUB 续传单独处理。书架与云端列表分别拆出 view/input 模块，云端数据读取和文库下载位于 cloud/data.rs。

新 DNS 结果优先 IPv4、保留 IPv6 回退；TCP/TLS 连接失败会尝试其他地址。HTTP 读取超时后最多对 GET/HEAD 用新连接重试一次，失败地址后置、成功地址优先，不固定 CDN IP。API GET 协商 gzip，按 8 MiB 解压上限还原响应，降低章节传输量。连续两次传输失败才进入 5–30 秒的短暂退避，同时失败的旧请求不继续延长退避。休眠唤醒后丢弃空闲连接、旧 DNS 和退避状态，重新适应 Wi-Fi 网络。

短暂操作反馈通过运行时 Toast 展示并在两秒后恢复，加载和错误仍保留页面状态。目录首次打开定位最近阅读章节并显示“当前”；书签元数据增加创建时间，旧元组继续可读。列表徽章仅使用现有接口字段，文库列表未返回等级时显示“文库”。

进入父页后请求的后续导航不依赖后台消息触发，运行时以有界循环消费，确保书签经目录直接返回阅读器；主机预览遵循相同规则。

启动后直接进入首页或密码弹窗，不绘制 splash 或额外等待首页数据。密码弹窗通过 Backdrop::Screen 读取实际系统画面或屏保，每次唤醒重新取图；应用内选项弹窗使用 Backdrop::CleanFrame 排除按钮按压反相。异常退出记录在 logs/，下次启动显示可关闭的恢复提示。安装成功后通过现有更新页请求热重启，启动器先恢复系统显示、释放锁，再执行新脚本；旧启动器不支持时保留手动重开说明，不新增 KUAL 菜单。
