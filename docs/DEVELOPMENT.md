# 开发说明

Kindlia 是独立的 AutoNovel Kindle 客户端，复用 KinNovel 的平台、渲染、分页与交互组件。上游归属与许可见 THIRD-PARTY-NOTICES.md 和 UPSTREAM-FILES.json；不依赖开发者的 KinNovel 工作目录。

接口以源站实际源码为准，核对入口见 PROTOCOL.md。普通读者功能包括账号、收藏、阅读历史、发现、搜索、排行、书籍评论和文库下载阅读；不接入论坛页面、小说上传编辑、翻译任务管理或 KinNovel 的账号与自动更新服务。

## KinNovel 参考基线

当前基线为 [KinNovel v1.6.8 / 4bcfee767ba0ae3f154c189646d406951bb61f89](https://github.com/mmnnwjw/KinNovel/commit/4bcfee767ba0ae3f154c189646d406951bb61f89)，上一基线为 v1.6.6 / 3f89ad2953bfda5378d9856aea5bb4c7ebc09265。仅使用已提交源码；开发者工作目录中的未提交修改不属于基线。

已移植两版之间适用的平台更新：广告版屏保模块的卸载与恢复、自定义休眠封面期间保持窗口管理器暂停、原生状态栏的停用与恢复、退出后恢复帧缓冲并刷新，以及 Scribe 启动方向和不同代 Oasis 陀螺仪编码处理。启动锁、临时文件及持久性数据路径仍与 KinNovel 隔离；不移植其自动更新、账号服务、产品版本号或历史发布文档。复用文件及适配差异记录在 UPSTREAM-FILES.json。

阅读器插图只对已解码位图实际显示的矩形开放全屏预览，不包含分页预留框中的留白。阅读统计入口位于「我的 → 阅读统计」，沿用 KinNovel 的今日、近 7 天、累计、连续天数、14 天图表和书籍排行。统计仅保存在程序目录内的 data/stats.json，不上传；单页计时上限 5 分钟，每 20 次有效翻页及离开阅读器、换章、休眠时保存，加载或浏览子页面期间不计时。同一文库书的已知来源卷合并统计。

## 开发与配置

构建、安装和字体路径见根目录 README.md。默认直连，反代地址与密钥为空；反代需用户自行部署并配置，见 GATEWAY.md。已有配置不会因默认值调整而被覆盖。

段间距 paragraph_spacing 默认 0.1，设置界面范围 0–2.0，步进 0.05，排版器不支持负段距。它以基础行高为单位增加文本块后的间隔，中日对照里的译文和日文各自属于一个文本块。EPUB 富文本（包括标题）的段后间隔取该值与 CSS margin-bottom 的较大值，并另外保留下个块的 margin-top；0 不会抹去源文件样式或独立空段。非富文本标题、图片和分隔线使用各自的间隔。行高 line_spacing 默认 1.4，设置界面范围 1.0–2.0，步进 0.05；它以字号的倍数控制同一段内的行高。

设备程序与持久性数据统一放在 /mnt/us/extensions/kindlia/ 内，包括配置、会话、字体、日志、缓存和备份。旧目录自动迁入该目录，冲突文件和迁移备份保留在内部 backups/。普通更新保留数据，清洁安装需要显式指定。

本地数据、账号文件、构建产物、诊断截图与日志不进入 Git。性能调试报告、设备测试记录、迁移交接及历史发布记录保留在被忽略的本地目录，不上传仓库。不要在提交中加入真实反代密钥、密码、令牌、设备 IP 或 SSH 指纹。

## EPUB 支持范围

支持 EPUB2 NCX、EPUB3 nav 目录、XHTML 正文、栅格插图及嵌有栅格图片的 SVG 封面；支持常用内联/外链 CSS 选择器及粗体、对齐、缩进、间距、隐藏等排版属性，以及跨文件注释。目录按 spine 和有效锚点组织，正文渐进分页，缓存最近章节和邻页位图。

尚不支持完整浏览器 CSS、@import/@media/@font-face、内嵌字体、复杂表格/浮动、竖排或任意纯矢量 SVG。无 BOM 的 UTF-16 和其他旧编码不保证支持。单章 CSS、规则匹配和注释解析有资源上限；超限会明确报错，缺失可选 CSS 会跳过。

## 性能调试

优先实际登录、浏览和阅读操作，在本地保存输入、显示画面和分阶段耗时。模拟器的 TCG 时间不能替代实机 CPU 或面板的光学测量。旧观察记录不能当作当前版本已重新验证的证据。

KN_DEBUG 启用输入与刷新诊断；账号输入时关闭，避免输入日志包含敏感信息。诊断文件应保留在被忽略的 build 目录或设备程序目录内。
